## 📖 About

Aurelio Portfolio is my personal developer portfolio built to showcase my projects, technical skills, and approach to creating interactive web experiences.

The site combines modern frontend development with animations, WebGL effects, and interactive 3D elements while keeping the main focus on my work and experience.

---

## ✨ Core Features

* **Project Showcase** — Displays my main software development projects and the technologies used to build them.
* **Interactive Visuals** — Uses WebGL, Three.js, and React Three Fiber to create interactive visual experiences.
* **Smooth Animations** — Motion and custom animations are used throughout the site to make sections feel more dynamic.
* **Contact Form** — Visitors can contact me directly through the portfolio using Resend.
* **Responsive Design** — Built to work across desktop and mobile screen sizes.

---

## ⚙️ How It Works

The portfolio is built with **Next.js and React**, with **Tailwind CSS** handling the main styling.

Interactive 3D elements are powered by **Three.js and React Three Fiber**, while **WebGL Fluid Simulation** is used for the animated background effects.

The contact form sends messages through **Resend**, keeping email credentials securely on the server through environment variables.

The application can run locally or through **Docker** and is deployed on **Vercel**.
